# Privacidad

Hushward funciona localmente y no requiere cuenta. No recopila telemetría,
analítica, identificadores de instalación, nombre de equipo/usuario, contenido
de audio o vídeo, capturas, portapapeles, títulos, URLs, documentos ni teclas.

Los detectores entregan evidencia clasificada: activo/inactivo, categoría,
confianza, salud y antigüedad. El historial guarda resultados y códigos
limitados por retención. Los diagnósticos se generan solo por petición, son
revisables y se redactan antes de exportar.

La única red permitida es el catálogo Velopack de GitHub Releases tras una
comprobación manual o consentimiento explícito. No añade cabeceras analíticas ni
datos de configuración. Ejecuta `scripts\Verify-Privacy.ps1` para auditar límites.
